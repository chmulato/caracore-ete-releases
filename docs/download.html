Minerador 4.0 · v1.2.3

Baixar e instalar

Três passos. O mesmo programa abre em modo Free; o Premium desbloqueia depois, se precisar.

  1. Baixe o ficheiro do seu sistema

    No Windows, use o botão dourado. Linux e macOS estão abaixo.

  2. Instale

    Windows: duplo clique no .exe (cerca de 34 MB). Se o SmartScreen avisar, escolha Mais informações → Executar. Linux: extraia o .tar.gz e corra Minerador40/Minerador40. macOS: abra o .dmg e use a pasta Minerador40.

  3. Abra o simulador

    A janela sobe sozinha. Se no Windows faltar o motor da janela, instale o WebView2.

Outros sistemas

  • Linux — baixar .tar.gz Extrair e executar Minerador40/Minerador40. Não separe o binário da pasta.

  • Windows — pasta em ZIP Só se preferir pasta em vez do .exe único: extraia e corra o .exe dentro da pasta.
